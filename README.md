A newspaper front page for a single day: Monday 23 November 2026. The image in `entry.png` was drawn entirely with code (Python + PIL, see `draw.py`) — no AI image generation — and sums up the day's leading world stories: Nvidia reinstating Jensen Huang as CEO 11 days after he quit, sending its shares up 33% and Wall Street roaring back; the COP31 climate summit in Antalya collapsing with no deal after the draft dropped fossil fuels; Ukraine sinking the Russian corvette Merkury off Benghazi with seven sea drones; the death toll rising to 11 in the Russian drone strike on a block of flats in Dymer near Kyiv; India pledging $1.6bn to help Nepal rebuild after August's glacier flood; the Democrats winning their biggest House majority since 1992; and Brentford beating Everton 4-0 on Monday night. The Node program `main.ts` simply copies that image to the output directory, byte for byte.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
